# Инструкция: Instagram, наличие, СДЭК и оплата Точка Банк

Все ключи и пароли вводятся в Netlify: **Project configuration → Environment variables → Add a variable**. В код их не вписывать. Полный список переменных — в файле `.env.example`. После добавления переменных нажмите **Deploys → Trigger deploy → Deploy project**, чтобы сайт их подхватил.

Обязательно задайте `SITE_URL=https://gluhovanatalya.ru` и `ADMIN_PASSWORD` — пароль страницы управления (не короче 10 символов).

## 1. Автоматическое наличие и новые товары из Instagram

### Как это работает
Каждые 15 минут сайт сам читает последние 50 постов в Instagram @natalkagluhova и разбирает подпись к каждому посту:

- **Новый товар.** Если в подписи есть название и цена, на сайте появляется карточка с фото из поста (все фото карусели), ценой, размерами и разделом.
- **Нет в наличии.** Если в подписи есть слова «Нет в наличии» (или «распродано», «sold out», `#нетвналичии`), на карточке появляется пометка, купить нельзя.
- **Закончился размер.** Строка «Закончились размеры: M» зачёркивает размер M, его нельзя выбрать.
- **Удалили пост** — товар скрывается с сайта.

Посты без цены (обычные фото, отзывы) сайт пропускает.

### Как писать подпись к посту с новым товаром
```
Кардиган в молочном цвете
Мягкая вискоза, ручная отделка
Цена: 9 500
Размеры: XS/S, M
#новинка
```
- **Первая строка** — название товара.
- **«Цена:»** — число в рублях.
- **«Размеры:»** — через запятую. Если строки нет или написано «единый», ставится «единый размер».
- **Раздел** определяется по названию: платье, юбка, костюм/комплект, кардиган, свитер/джемпер/кофта. Можно указать явно строкой «Раздел: кардиганы».
- **Остальные строки** становятся описанием на сайте.

### Как отмечать наличие
Отредактируйте подпись поста этого товара (в Instagram: «…» → «Редактировать»), добавьте строку:
```
Нет в наличии
```
или
```
Закончились размеры: M
```
Когда товар снова есть — удалите эту строку. Через 15 минут сайт обновится.

### Товары, которые уже есть на сайте (25 штук)
Они созданы до подключения Instagram. Чтобы управлять их наличием через Instagram, добавьте в подпись любого поста строку с кодом товара. Коды видны на странице управления (`/admin.html`, «код: …»).
```
Код: kardigan-v-rozovom-cvete
Закончились размеры: XS/S
```

### Сторис
Текст в сторис — это картинка, сайт не может его прочитать. Для быстрых отметок используйте подпись поста или страницу управления.

### Подключение Instagram (один раз)
1. **Профессиональный аккаунт.** В приложении Instagram: Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт («Автор» или «Бизнес»).
2. **Приложение Meta.** На developers.facebook.com войдите, нажмите **My Apps → Create App**. Выберите сценарий «Manage messaging & content on Instagram» (Instagram API с входом через Instagram).
3. **Токен.** В приложении откройте **Instagram → API setup with Instagram login → Generate access tokens → Add account**. Войдите в @natalkagluhova, разрешите доступ и скопируйте токен.
4. **Netlify.** Добавьте переменную `IG_ACCESS_TOKEN` с этим токеном. Сайт сам продлевает его раз в неделю.
5. **Проверка.** Откройте `https://gluhovanatalya.ru/admin.html`, нажмите «Синхронизировать с Instagram». В «Журнале» появится результат.

Учтите: компания Meta (владелец Instagram) признана в России экстремистской организацией. Пользоваться Instagram не запрещено, но если вы не хотите зависеть от него, используйте страницу управления (ниже) — она полностью заменяет Instagram.

### Если Instagram не подключится — другие способы
1. **Страница управления `/admin.html` (уже работает).** Вход по паролю `ADMIN_PASSWORD`. Можно:
   - отметить товар «Нет в наличии»;
   - зачеркнуть отдельные размеры;
   - добавить новый товар с фото с телефона;
   - скрыть товар;
   - посмотреть заказы.
   Ручные отметки важнее Instagram. Кнопка «Авто» возвращает товар под управление Instagram.
2. **Telegram-бот.** Владелец пишет боту «нет M кардиган» или присылает фото с подписью — бот обновляет сайт. Можно добавить по запросу.
3. **Учётная программа (МойСклад и др.).** Если остатки ведутся в учётной программе, сайт может забирать наличие оттуда по API. Можно добавить по запросу.

## 2. Подключение СДЭК

Сайт уже считает стоимость и сроки доставки СДЭК, показывает пункты выдачи и курьерскую доставку. Нужен только договор и ключи.

1. **Договор.** Заключите договор со СДЭК как интернет-магазин (ИП) на cdek.ru → «Бизнесу» → «Интернет-магазинам». Тариф — «склад-склад» и «склад-дверь».
2. **Ключи API.** В личном кабинете lk.cdek.ru откройте **Интеграция → Ключи для API (ИМ)** и скопируйте **Account** и **Secure password**.
3. **Переменные в Netlify:**
   - `CDEK_CLIENT_ID` = Account
   - `CDEK_CLIENT_SECRET` = Secure password
   - `CDEK_FROM_CITY_CODE` = `250` (Екатеринбург)
   - `CDEK_API_URL` = `https://api.cdek.ru/v2` (для теста: `https://api.edu.cdek.ru/v2` с тестовыми ключами из документации СДЭК)
4. **Вес и размер посылки.** Сейчас в расчёте 700 г на изделие и коробка 35×30×8 см. Поменять можно в `netlify/lib/cdek.js`.
5. **Отправка заказа.** Сайт рассчитывает доставку и принимает оплату. Отправление в СДЭК оформляется в личном кабинете СДЭК по данным заказа со страницы управления (вкладка «Заказы»: адрес, ПВЗ, телефон). Автоматическое создание отправлений можно добавить позже.
6. **Проверка.** На сайте положите товар в корзину → «Оформить заказ» → введите город. Должны появиться стоимость доставки и список пунктов выдачи.

## 3. Подключение оплаты Точка Банк

Сайт создаёт в Точке платёжную ссылку с чеком по 54-ФЗ. Покупатель платит картой или через СБП, затем возвращается на сайт.

1. **Счёт и эквайринг.** Нужен расчётный счёт ИП в Точке. В интернет-банке Точки откройте **Эквайринг → Интернет-эквайринг → Подключить**, укажите сайт `gluhovanatalya.ru`.
   Банк проверит сайт. Нужны оферта, политика конфиденциальности, контакты, реквизиты ИП, цены, условия доставки и возврата — эти страницы на сайте есть. Тексты оферты и возврата перед проверкой стоит вычитать с юристом.
2. **Чеки.** При подключении эквайринга включите отправку чеков покупателям (онлайн-касса через Точку). Без этого запрос с чеком не пройдёт.
3. **JWT-ключ.** Интернет-банк → **Интеграции и API → Подключить → Создать JWT-ключ**. Дайте права на интернет-эквайринг (просмотр и создание операций). Скопируйте ключ — он показывается один раз.
4. **Код клиента и ID торговой точки.**
   - `TOCHKA_CUSTOMER_CODE` — 9-значный код вашей компании в Точке. Его можно узнать у поддержки Точки или в интернет-банке.
   - `TOCHKA_MERCHANT_ID` — 15-значный ID торговой точки. Нужен, только если торговых точек несколько.
5. **Переменные в Netlify:**
   - `PAYMENT_PROVIDER` = `tochka`
   - `TOCHKA_JWT` = JWT-ключ
   - `TOCHKA_CUSTOMER_CODE`, `TOCHKA_MERCHANT_ID` (если есть)
   - `TOCHKA_TAX_SYSTEM` = ваша система налогообложения: `usn_income` (УСН «доходы»), `usn_income_outcome` (УСН «доходы минус расходы»), `osn`, `patent`. Значение уточните у бухгалтера.
6. **Тест.** Сделайте заказ на сайте на небольшую сумму. Проверьте, что открылась страница оплаты Точки, что после оплаты вы вернулись на сайт и что покупателю пришёл чек.

Если Точка вернёт ошибку, на сайте появится «Платёжный сервис отклонил запрос». Текст ошибки Точки будет в Netlify: **Logs → Functions → create-order**. Пришлите его мне, и я поправлю запрос.

Названия полей запроса к Точке написаны по документации банка (метод `acquiring/v1.0/payments_with_receipt`). Сайт документации Точки был недоступен из среды разработки, поэтому первый тестовый платёж обязателен.

Если вернуться к ЮKassa: `PAYMENT_PROVIDER=yookassa` и ключи `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`.

## 4. Заказы
Все созданные заказы видны на странице управления, вкладка «Заказы»: дата, покупатель, телефон, почта, доставка, состав, сумма. Там же видны неоплаченные заказы (покупатель открыл оплату, но не заплатил). Факт оплаты проверяйте в интернет-банке Точки по номеру заказа (`GN-…`).
