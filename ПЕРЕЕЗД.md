# Переезд сайта с Netlify на свой сервер в России

Netlify заблокирован в России, поэтому сайт открывается только через VPN. Сайт переезжает на свой сервер (VPS) в России. После переезда:
- сайт открывается без VPN;
- работает всё, что было: каталог, заказы, СДЭК, оплата, страница управления, наличие;
- сайт сам обновляется из GitHub в течение 2 минут после изменений, коммиты партнёра для публикации больше не нужны.

Время: 30–40 минут. Нужен доступ к Beget и к GitHub (аккаунт sitenatalyan-spec).

---

## Шаг 1. Купить VPS в Beget
1. Beget → **VPS** → **Создать сервер**.
2. Операционная система: **Ubuntu 24.04**.
3. Конфигурация: 1 ядро, 1–2 ГБ памяти, 10+ ГБ диска. Этого хватает.
4. Расположение: **Россия**.
5. После создания Beget покажет **IP-адрес** сервера и **пароль root**. Сохраните их.

## Шаг 2. Открыть консоль сервера
В панели Beget откройте созданный VPS → **Консоль** (или подключитесь с компьютера: `ssh root@IP-адрес`).
Войдите как `root` с паролем из шага 1.

## Шаг 3. Запустить установку
1. На GitHub откройте репозиторий → папка `deploy` → файл `setup.sh` → кнопка **Raw**.
2. Скопируйте адрес страницы из адресной строки браузера. Для закрытого репозитория в нём будет `?token=…` — это нормально, ссылка временная.
3. В консоли сервера вставьте (адрес в кавычках замените своим):
   ```
   curl -fsSL 'СКОПИРОВАННЫЙ_АДРЕС' -o setup.sh && bash setup.sh
   ```
4. Скрипт покажет строку, начинающуюся с `ssh-ed25519 …`. Это ключ сервера. Добавьте его на GitHub:
   репозиторий → **Settings** → **Deploy keys** → **Add deploy key** → Title: `server`, Key: вставить строку, галочку «Allow write access» **не** ставить → **Add key**.
   Вернитесь в консоль и нажмите **Enter**.
5. Скрипт покажет **пароль страницы управления** (`/admin.html`). Сохраните его.

## Шаг 4. Направить домен на новый сервер
Beget → **Домены и поддомены** → **DNS** для `gluhovanatalya.ru`:
- запись **A** для `@` (сам домен) → IP-адрес сервера (старое значение `75.2.60.5` удалить);
- запись **A** для `www` → тот же IP-адрес (если там CNAME на Netlify — удалить).

Подождите 15–60 минут, пока изменения разойдутся, и выполните в консоли сервера:
```
certbot --nginx -d gluhovanatalya.ru -d www.gluhovanatalya.ru --redirect --agree-tos --register-unsafely-without-email
```
Это выпустит бесплатный сертификат https (продлевается автоматически).

## Шаг 5. Вписать ключи (СДЭК, Точка Банк, Instagram)
Ключи теперь хранятся не в Netlify, а на сервере. В консоли:
```
nano /etc/gluhova.env
```
Впишите значения после `=` (что где взять — в `ИНСТРУКЦИЯ.md`). Сохранить: **Ctrl+O**, **Enter**, выйти: **Ctrl+X**. Затем:
```
systemctl restart gluhova
```

## Шаг 6. Проверить
- Откройте https://gluhovanatalya.ru **без VPN** — с телефона через мобильный интернет и с домашнего Wi-Fi.
- Откройте https://gluhovanatalya.ru/admin.html и войдите с паролем из шага 3.
- Netlify после этого можно отключить: в Netlify → Deploys → **Lock to stop auto publishing** (или удалить проект).

---

## Полезные команды на сервере
- Состояние сайта: `systemctl status gluhova`
- Журнал ошибок в реальном времени: `journalctl -u gluhova -f`
- Обновить сайт из GitHub немедленно: `gluhova-update`
- Данные (наличие, заказы, фото из Instagram): папка `/var/lib/gluhova` — её стоит периодически копировать (Beget → VPS → резервные копии).

## Что может не работать из России
- **Instagram.** Сервер в России может не иметь доступа к Instagram. Проверьте на странице управления: кнопка «Синхронизировать с Instagram», затем вкладка «Журнал». Если там ошибка соединения — синхронизацию можно перенести на GitHub (он работает за рубежом и передаёт данные на сайт); страница управления работает в любом случае.
- **Вход в аккаунт.** Работает на этом же сервере (вход через Google и по SMS-коду), сторонние сервисы вроде Supabase больше не нужны. Настройка — в `ИНСТРУКЦИЯ.md`, раздел 5.
